zeyada

Neoxero · E-commerce · Flutter

A family of e-commerce apps for the Saudi market, built from one reusable architecture.

Context
E-commerce apps on a Saudi e-commerce platform
Stack
Flutter, Dart, Clean Architecture, Bloc
My role
Base architecture and the home-screen data layer

Problem

Launch several similar stores without copying code, and without a home-page API from the platform.

Architecture

A reusable modular base using Clean Architecture and Bloc, so a new store is mostly configuration and theming.

The hard part

The platform exposed the home page only as server-rendered HTML, with the section data embedded as an escaped JSON string and no schema. I parse the HTML, extract each section by its data attribute, decode the JSON, filter by visibility and platform rules, map each section into a typed entity and return them in order. The app renders the home screen as if it were API-driven.

Not every system is API-driven. The skill is understanding how data reaches the UI.
