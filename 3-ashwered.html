Ashwered

Neoxero · Magento · Native channels

A Flutter e-commerce app on Magento GraphQL where payments needed a hybrid approach.

Context
E-commerce app for the Saudi market
Stack
Flutter, Kotlin, Swift, Magento GraphQL, Firebase
Features
Catalog, filtering and sorting, wishlist, cart, checkout, order tracking, AR/EN, push notifications

Problem

The available Magento payment modules caused problems in the app.

Solution

I split payments by method. Some methods run in a WebView and keep the module's own flow. The others use native channels, Kotlin on Android and Swift on iOS, connected to Flutter.

When a third-party backend limits you, choose a pragmatic hybrid per case instead of forcing one approach everywhere.
